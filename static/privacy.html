Privacy

Park Patrol shows which parking spots are free in Lot A. Here is what it collects, and how that is protected.

Checking the lot

You don't need an account to see the lot. The public page doesn't ask for your name and doesn't use tracking or advertising cookies.

The camera

  • One camera watches Lot A to tell which spots are taken. It is used only for parking.
  • The live video is not public. Only signed-in campus security admins can see it.
  • When a car is double-parked, a single picture is saved so security can follow up. It is stored encrypted.

Telegram spot alerts

  • If you subscribe, we keep only your Telegram chat ID, so we can message you when a spot opens. We never see your name, phone number or email.
  • The chat ID is stored encrypted. Send /stop to the bot anytime to unsubscribe.

Admins

  • Security admins sign in with Google. Their email, name and profile photo link are stored encrypted.
  • The sign-in log records only whether a sign-in succeeded and when. For failed attempts, nothing is stored about who tried.

How it's protected

Personal details are encrypted with AES-256-GCM before they are saved, and the encryption key is kept separate from the database. Connections to the website and the database are encrypted.
